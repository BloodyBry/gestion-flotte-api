# API de gestion de flotte routière

Projet de formation réalisé avec Node.js, Express et MongoDB.

## Fonctionnalités prévues

- Gestion des camions, remorques et pneus.
- Gestion des chauffeurs et des trajets.
- Suivi du kilométrage et du carburant.
- Alertes de maintenance.
- Génération des ordres de mission PDF.

## État du projet

Projet en cours de développement.
